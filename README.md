
# ✨ BlogSpace 📝🚀

## 📸 Sneak Peek  
👀 *Want a space where you can write your thoughts, read others', and just blog like a boss?*  
BlogSpace brings you a minimalist, modern, and magical blogging experience — like Medium, but made with love ❤️ and TypeScript ⚙️.

---

## 📂 Project Structure
```
blogspace/
├── client/       📱 Frontend (React + TailwindCSS)
├── server/       🔧 Backend (Node.js + Express + Drizzle ORM)
├── shared/       🤝 Shared types for frontend/backend
├── drizzle.config.ts  🧙 DB Config with Drizzle Magic
├── tailwind.config.ts 🎨 Custom Tailwind setup
├── theme.json         🌈 Theme file for styling
├── vite.config.ts     ⚡ Fast build with Vite
```

## ⚙️ Tech Stack

| Layer      | Tech Used 🚀 |

## 🛠️ Setup Instructions

1. **Clone the repo:**
   ```bash
   git clone https://github.com/Meghraj2004/blogspace.git
   cd blogspace
   ```

2. **Install dependencies for frontend and backend:**
   ```bash
   cd client && npm install
   cd ../server && npm install
   ```

3. **Start the dev server:**
   ```bash
   # In two separate terminals
   cd client && npm run dev     # Frontend
   cd server && npm run dev     # Backend
   ```

4. **Configure DB & Drizzle (optional):**  
   Update `drizzle.config.ts` and run migrations as needed.
